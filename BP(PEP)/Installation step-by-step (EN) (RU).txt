https://www.mixmods.com.br/2022/10/open-limit-adjuster/

  5. Now you can install almost any modern modification. I'll tell you how to install my modifications: We throw the mod folder into the modloader folder. 
For example, the Busy Pedestrians mod (Peds Events Project) is "Grand Theft Auto - San Andreas\modloader\Busy Pedestrians (Peds Events Project)". That's it! Now we launch the game and enjoy it.
