- Mod Info - 

This mod is a pack of two new Peds for your game, US Postal Workers.

You get two models with this pack!

1) The Classic Letter Carrier Shorts

2) Letter Carrier Pants

Both models come with a pith helmet for the blazing sun of SA, and a lore friendly US Mail patch.

-----------------------------------------MOD INSTALLATION ---------------------------------------------
Tools you will need before hand.  
===Mod Loader===
DL: https://gtaforums.com/topic/669520-mod-loader/ 

///////////// INSTALLING THE MOD ///////////////////

1) Drag the "Postal Workers" Folder inside the "To Modloader!" to, well Modloader lol.

2) Edit the "ID" line in the PedIDs.txt file inside the "Postal Workers" Folder to a FREE-ID so you'll be able to spawn and use them.

3) Enjoy! 

BONUS STEP.
4) For Better immersion in your game use the peds with ArtemQa146's Postman Script.
 Mod Download: https://www.gtainside.com/en/sanandreas/mods/195041-postman/
